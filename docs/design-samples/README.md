# Design samples

Static HTML copies of the samples the owner approved on the design canvas. Open any file in a browser to see it. The `<x-dc>`, `<helmet>` tags and the script block at the bottom come from the canvas editor and do nothing here; the inline styles are the design.

| File | What it shows | Status |
| --- | --- | --- |
| `today-bento.html` | Admin home ("Today"), laptop | Chosen. Built in step 2 |
| `repairs-board.html` | Repairs page as a board by status, laptop | Chosen for step 3 |
| `repair-page-split.html` | Use only the right-hand part (big blue header card, steps, Customer and Money cards) for the repair page. The list on the left is not used | Chosen for step 3 |
| `new-repair-phone.html` | New repair form on a phone, first round of samples | Reference for spacing only; the colours are from an older style |
| `homepage.html` | Public homepage, style "A Bright" | Chosen for step 4 |
| `admin-nav.html` | Admin menu: navy sidebar on laptop, bottom bar and "More" panel on phone | Chosen. Built in step 5 |
| `settings.html` | Settings page with section menu and unsaved-changes bar | Chosen for step 6 |
| `bill.html` | Bill redesign: admin builder (laptop and phone), Record payment sheet, customer bill link (part paid and paid), printed A4 | Chosen. Built in step 7 |
| `repairs-board-laptop-fix.html` | Repairs board on a 1366px laptop: A compact cards, B wider columns that slide | Not used: the board was replaced by the list and a By step view with wide cards |
| `repairs-active-list.html` | Repairs page opening on all active repairs: 1 list like an orders page, 2 grouped by what needs doing, 3 list with the repair beside it. Laptop and phone | 1 chosen as the default list, 3 as the Side by side view. Built |

All names, phone numbers, devices and prices in these samples are invented. The phone drawings are placeholders for photos.
